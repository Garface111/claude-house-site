Claude House

A private home assistant for one household.

Claude House runs on the household's own computer. It turns the household's own lights, TV and thermostat on and off, and adjusts them, when someone in the home asks by voice, and it can run routines they set up themselves.

It is not a public service. It has no sign-ups and no users outside that one home, and it never asks anyone else for access to their devices.

To control the household's Nest thermostat it uses Google's Smart Device Management API, with the permission of the account that owns the thermostat. The privacy policy explains exactly what it reads and where that goes.
